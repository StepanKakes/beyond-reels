Instalace

Jednou na každém Macu s Apple čipem, asi deset minut. Helvetica se nikam neposílá, setup si ji vezme ze systému tvého Macu

Plugin

zip od Štěpána

Rozbal beyond-reels-plugin.zip do ~/Documents/beyond-reels-plugin a v Claude Code napiš

/plugin marketplace add ~/Documents/beyond-reels-plugin
/plugin install beyond-reels@beyond

Média

hudba a B-rolly, 1 GB

Rozbal beyond-reels-media.zip do ~/Documents/beyond-reels-media

Setup

nástroje, Python, písmo, přepisy
zsh ~/Documents/beyond-reels-plugin/plugins/beyond-reels/scripts/setup.sh

Pro text za lidmi přidej --matanyone, co chybí ukáže --kontrola

Co napsat

Mluv normálně. Příkaz jen řekne, který postup se má spustit

/reel
„udělej reel jako mason z ~/Downloads/rozhovor.mp4, je to rozbor George Heatona“
celý postup od videa po revizi
/revize
„přečti feedback k heaton v3“
komentáře, opravy, nová verze, knihovna komponent
/novy-styl
„nauč se styl tohohle tvůrce, tady jsou 4 reely“
rozbor po snímcích, kit, ukázka a nový styl pro celý tým

Co hlídá sám

Pravidla, která jste s Timem nastavili na Dalenovi, Heatonovi a dalších. Nové přibývají z revizí

  • Každé video je originál, knihovna jen inspiruje
  • Žádný koncept, který přebalí celou pasáž do metafory
  • Firmy záběrem s logem, nikdy napsaným názvem
  • Tim jen při pohledu do kamery
  • Titulky celé, aspoň 13 snímků, nikdy přes obličej
  • Helvetica Neue Bold, nikdy kurzíva
  • Žádné glow, glitch, strobo ani nafukování z nuly
  • Střih do ticha, kontrola useknutých slov
  • Hlas −5,5 dB, hudba −24 dB se sidechainem
  • Storyboard před renderem, vždy

Když něco nejde

Skoro vždycky to vyřeší setup s parametrem --kontrola
